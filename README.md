# Lao21staff • ค่ายวิศวะเหลาดินสอ ครั้งที่ 21 (ระบบคัดกรองและประเมินสตาฟ)

เว็บแอปพลิเคชันที่เชื่อมโยงข้อมูลจากแบบฟอร์มการตอบกลับของ Google Forms / Excel (`ค่ายวิศวะเหลาดินสอ ครั้งที่ 21 (การตอบกลับ).xlsx`) ออกแบบมาเพื่อให้อ่าน เปรียบเทียบ และประเมินคำตอบของผู้สมัครได้อย่างสะดวกรวดเร็ว

---

## 🚀 วิธีเปิดใช้งาน

คุณสามารถเปิดใช้งานได้ 2 วิธีง่ายๆ:

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `start_app.bat` (แนะนำ)
- ดับเบิลคลิกที่ไฟล์ **`start_app.bat`**
- ระบบจะเปิด Local Web Server และเปิดเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:8000`
- วิธีนี้จะรองรับการกดปุ่ม **"ซิงค์ Excel"** หากมีการแก้ไขไฟล์ Excel ในอนาคต

### วิธีที่ 2: ดับเบิลคลิกเปิดไฟล์ `index.html` โดยตรง
- สามารถเปิดไฟล์ **`index.html`** ด้วย Google Chrome หรือ Microsoft Edge ได้ทันที (มีข้อมูลแคชออฟไลน์ `data.js` ในตัว)

## 🎨 สรุปฟีเจอร์เด่นของระบบ

### 1. UX/UI Minimal เรียบง่ายโทนขาว-เทา
- ออกแบบคลีน สบายตา รองรับฟอนต์ Prompt (ภาษาไทย) และ Inter (ตัวเลขและภาษาอังกฤษ)
- อ่านง่าย ไม่รกตา โทนสีขาว เทา ดำ (Monochrome Slate / Zinc)

### 2. ระบบคัดกรองและการตัดสิทธิ์ตามเงื่อนไข (*สำคัญ)
- **ตัดสิทธิ์อัตโนมัติ 5 รายชื่อ:**
  1. **ชินานันท์ ธนะสุชาวิรัตน์** (ชื่อแดงในแบบฟอร์ม)
  2. **ฐานนท์ โออินทร์** (ชื่อแดง, ชื่อเหลือง, รหัสนักศึกษา 67)
  3. **พีรภัทร แสงสุรินทร์** (ชื่อแดง, ชื่อเหลือง, รหัสนักศึกษา 67)
  4. **ณัฐวัฒน์ พันธุ์พานิช** (ชื่อแดงในแบบฟอร์ม)
  5. **ณัฐมล อัมพรสินธุ์** (ชื่อแดงในแบบฟอร์ม)
- **รหัสนักศึกษา 67:** ตัดออกไม่นำมาคิดเป็นค่าเริ่มต้นตามที่กำหนด
- มีปุ่ม Modal สามารถคลิกตรวจสอบรายชื่อทั้ง 5 คนที่ถูกตัดสิทธิ์ได้ตลอดเวลาเพื่อความโปร่งใส

### 3. ตัวกรองครบครัน (Multi-dimension Filters)
- **แบ่งตามฝ่าย (11 ฝ่าย):** พี่บ้าน, กิจกรรม, สถานที่, สวัสดิการ, พยาบาล, ทะเบียน, สปอนเซอร์, ศิลป์, ประชาสัมพันธ์, รันสคริป์, โสตทัศนศึกษา
- **อันดับที่สมัคร:** ตัวกรองเฉพาะอันดับ 1 / อันดับ 2 / ทั้งหมด
- **รหัสนักศึกษา:** เฉพาะรหัส 69 (ปี 1) / เฉพาะรหัส 68 (ปี 2) / ทั้งหมด
- **เพศ:** ชาย / หญิง / ทั้งหมด
- **ภาควิชา:** เลือกกรองตามสาขาวิศวกรรมศาสตร์
- **ค้นหาอิสระ:** ค้นหาตามชื่อ, ชื่อเล่น, รหัสนักศึกษา, สาขาวิชา หรือคีย์เวิร์ดในคำตอบ

### 4. การแยกชุดคำถามอย่างชัดเจน
เมื่อกดดูข้อมูลผู้สมัครแต่ละคน ระบบจะแบ่งแท็บออกเป็น:
- **📌 คำถามทั่วไป (6 ข้อ):** แนะนำตัว, ประสบการณ์ค่าย, ความคาดหวัง, จุดเด่น, การแก้ปัญหาความขัดแย้ง, การรับมือกับงานด่วน
- **🎯 คำถามเฉพาะฝ่าย (อันดับ 1 & อันดับ 2):** คำถามและคำตอบเจาะจงของแต่ละฝ่าย
- **📞 ข้อมูลติดต่อ & วันสัมภาษณ์:** เบอร์โทร, LINE, วันสัมภาษณ์ที่สะดวก (10-11 ต.ค.)

### 5. โหมดเปรียบเทียบผู้สมัคร (Side-by-Side Comparison)
- สามารถกดปุ่ม **"เปรียบเทียบ"** บนการ์ดผู้สมัครที่สนใจ (เลือกได้สูงสุด 4 คนพร้อมกัน)
- แสดงตารางเปรียบเทียบคำถามข้อต่อข้อ ทั้งคำถามทั่วไปและคำถามเฉพาะฝ่าย
- ช่วยให้คณะกรรมการเห็นความแตกต่างของวิธีคิด ทัศนคติ และสไตล์การตอบได้อย่างชัดเจน

### 6. แดชบอร์ดสถิติภาพรวม (Analytics Dashboard)
- **กราฟแท่งความนิยมแต่ละฝ่าย:** เปรียบเทียบผู้สมัครอันดับ 1 vs อันดับ 2
- **กราฟสัดส่วนชั้นปี:** รหัส 68 vs รหัส 69 (พร้อม %)
- **กราฟสัดส่วนเพศ:** ชาย vs หญิง
- **กราฟการกระจายตัวตามภาควิชา:** ภาควิชาไหนมาสมัครมากที่สุด
- **กราฟประสบการณ์ค่าย:** สัดส่วนคนเคยทำค่าย vs ผู้สมัครใหม่
- **กราฟความสะดวกวันสัมภาษณ์:** 10 ต.ค. vs 11 ต.ค.
- **ตารางสรุปรายฝ่าย (Matrix):** ยอดสมัคร อันดับ 1, อันดับ 2, ชั้นปี, และเพศของทุกฝ่าย
